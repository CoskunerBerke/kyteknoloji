# KY Teknoloji — Kurumsal Web Sitesi

**KY Teknoloji (@kyteknoloji)** — Sincan 1. OSB Asora İş Merkezi (Boss Otel Yanı) lokasyonunda faaliyet gösteren akıllı telefon teknik servisi, ekran koruma, aksesuar ve sıfır / 2. el telefon alım-satım merkezi için hazırlanmış kurumsal web sitesi.

## Öne Çıkan Özellikler
- **Tam Ekran Loop Telefon Videosu (`Hero`):** Tüm mobil cihazlar (iOS Safari, Android Chrome) ve masaüstü tarayıcılarla tam uyumlu, arka planda kesintisiz dönen yüksek çözünürlüklü akıllı telefon videosu (`/ky/phone-hero.mp4`).
- **Durmayan Canlı Yorum Akışı (`ReviewRiver`):** Sağdan sola kesintisiz akan (`animate-river-continuous`), fare imleci (hover) veya dokunma geldiğinde kesinlikle durmayan müşteri yorumları.
- **Gerçek Instagram Verileri & Görselleri:** `@kyteknoloji` Instagram sayfasından çekilen gerçek ürün/uygulama fotoğrafları (`/ky/1.jpg` – `/ky/6.jpg`), hizmetler, güncel ekran koruyucu fiyatları ve Asora İş Merkezi (Sincan / Ankara) konum bilgileri.
- **Bilimsel Renk ve Tipografi Standartları:** WCAG AAA kontrast oranına sahip Karbon Antrasit (`#09090B` / `#18181B`), Kırık Beyaz (`#FAFAFA`) ve Kehribar Turuncu (`#EA580C`) renk paleti; `Outfit`, `Plus Jakarta Sans` ve `JetBrains Mono` tipografi hiyerarşisi.

## Geliştirme ve Derleme

```bash
npm install
npm run dev
npm run build
```
